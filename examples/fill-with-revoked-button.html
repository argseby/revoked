“Fill with revoked” button

A button any website can embed to point visitors at one of your requests. Clicking it opens the request in the revoked app — requests are answered only there, where the server is verified before anything is typed, so there is no web form for a phisher to imitate.

  1. In the app, open the request’s share sheet and copy the App link.
  2. Paste it below.
  3. Copy the snippet into your site’s HTML.

The button is a single self-contained anchor: inline styles, inline SVG, no script, no external assets. A visitor without the app installed sees nothing happen when they click, so pair the button with a line telling them where to get revoked.
