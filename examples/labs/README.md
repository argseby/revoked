# Lab files

Small files for the [labs](https://docs.revoked.link/labs/).

- `listen.py` prints every request it receives. The Collect and Prove labs use it.
- `guestbook/` is a tiny tool, one HTML file with no backend. The Connect lab uses it.
  It's the same page as in [Building a tool](../../docs/api/tools.md).
- For one runnable demo of all consent screens, use the
  [flow playground](../sign-in-demo/README.md#test-all-consent-screens).
